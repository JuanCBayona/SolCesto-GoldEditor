# SolCesto-GoldEditor
Script to edit your gold in the game

1. Download the script
2. Run this command to see your current amount of gold: python sc_gold.py show "$env:LOCALAPPDATA\SolCesto\EBWebView\Default\IndexedDB\https_app.localhost_0.indexeddb.leveldb"
3. Run this command to edit it (the last number is your new amount of gold): python sc_gold.py set "$env:LOCALAPPDATA\SolCesto\EBWebView\Default\IndexedDB\https_app.localhost_0.indexeddb.leveldb" 50000
